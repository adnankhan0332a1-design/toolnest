Google launch checklist

Production steps to complete after connecting a real domain.

Connect a domain

Publish ToolNest on an HTTPS domain and replace any placeholder production URLs before launch.

Create sitemap.xml

Add the homepage and important tool landing URLs to a real XML sitemap and submit it in Google Search Console.

Create robots.txt

Allow normal crawling of important pages and point crawlers to the production sitemap URL.

Verify Search Console

Verify site ownership, inspect important URLs and request indexing after the site is live.

Monitor performance

Use Search Console to review impressions, clicks, queries, pages and indexing issues.

Keep adding value

Expand with genuinely useful tools and original explanations instead of thin pages made only for search traffic.
